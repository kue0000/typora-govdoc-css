公文排版样式演示文档

本文件用于展示 Typora 公文排版样式的导出效果，涵盖各级标题、正文段落、表格、列表、引用等常见元素。

一、标题层级示例

（一）二级标题下的三级标题

正文采用仿宋三号字体，首行缩进两个字符，两端对齐。这是中国党政机关公文的标准排版格式，适用于通知、报告、请示、批复等各类公文。

四级标题示例

四级及以下标题使用仿宋加粗，左对齐，不缩进。在公文中通常用于三级标题下的进一步分类说明。

五级标题示例

五级标题与四级标题样式相同，实际公文中较少使用超过四级的标题层级。

（二）段落格式说明

公文正文的排版要求严格，需要确保字体统一、行距适当、缩进规范。本样式表针对以上要求进行了完整适配，确保导出 PDF 后与正式公文格式一致。

段落之间保留适当间距，既不过于紧凑也不过于松散，便于阅读和批注。

表格采用纯黑细线闭合边框，表头浅灰底色，整体风格与传统统计表一致。

三、列表示例

有序列表

  1. 第一项工作内容：完成前期调研和数据采集。
  2. 第二项工作内容：组织专家评审并形成初步方案。
  3. 第三项工作内容：向社会公众征求意见并修改完善。
  4. 第四项工作内容：提交上级部门审批并落实执行。

无序列表

  • 注意事项一：所有数据须经核实后方可引用。
  • 注意事项二：涉及敏感信息的内容不得对外公开。
  • 注意事项三：各环节负责人应按时提交进度报告。

嵌套列表

  1. 第一阶段：前期准备
    • 组建工作专班
    • 制定工作计划
    • 落实经费保障
  2. 第二阶段：组织实施
    • 开展现场调查
    • 编制规划方案
    • 组织专家论证
  3. 第三阶段：总结验收
    • 汇总成果资料
    • 编写总结报告
    • 做好经验推广

五、页边距与印刷规范

当前页边距设置为上方 1.5cm，其余三边各 1cm。如需调整为国标公文标准（上 35mm / 下 35mm / 左 28mm / 右 26mm），可在 CSS 文件中修改 @page 的 margin 值。

本样式还包含以下印刷优化措施：

  • 防止标题孤行（标题不会单独出现在页面底部）
  • 防止表格和代码块跨页断裂
  • 超链接显示为纯黑色无下划线，打印效果整洁
  • 图片居中显示，自动限制宽度不超出页面

本文档仅用于样式演示，不包含任何实际业务内容。
